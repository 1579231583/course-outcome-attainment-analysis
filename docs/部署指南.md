# 课程目标达成度分析系统 — 部署指南（Docker / MySQL / 本地开发）

本系统支持 **SQLite（零配置本地开发）** 与 **MySQL 8.0（生产级多教师并发）** 双引擎无缝切换，且提供开箱即用的 Docker Compose 一键部署方案。

---

## 方式一：Docker Compose 一键部署（推荐 · 传到任何服务器直接跑）

前提：目标服务器已安装 Docker 与 Docker Compose。

### 1. 上传项目并准备环境变量
```bash
# 进入项目根目录
cd 课程目标达成度分析系统

# 可选：复制环境变量模板并修改密码、端口（不复制也会使用默认配置直接启动）
cp .env.example .env
```

### 2. 一键构建并后台启动（应用 + MySQL 8.0）
```bash
docker compose up -d --build
```
等待首次构建与 MySQL 初始化完成后，浏览器直接访问：
- `http://服务器IP:8000`
- 默认管理员：`admin` / `admin123`
- 默认教师：`teacher` / `123456`（上线后请在管理员后台修改密码）

### 3. 常用运维命令
```bash
# 查看运行状态与日志
docker compose ps
docker compose logs -f app

# 更新代码后重新构建上线（MySQL 数据保存在 mysql_data 卷中，绝不丢失）
docker compose up -d --build

# 停止服务
docker compose down
```

---

## 方式二：学校内网无外网服务器离线部署

1. 在有外网的电脑上构建镜像并导出：
   ```bash
   docker compose build
   docker save -o obe-images.tar 课程目标达成度分析系统-app:latest mysql:8.0
   ```
2. 将 `obe-images.tar` 与 `docker-compose.yml`、`.env` 拷到学校内网服务器。
3. 在内网服务器导入并启动：
   ```bash
   docker load -i obe-images.tar
   docker compose up -d --no-build
   ```

## 方式三：本地开发直跑（无需 Docker）

### 1. 默认 SQLite 模式（零配置）
```powershell
cd backend
.\venv\Scripts\python.exe -m uvicorn api:app --reload --port 8000
```
数据保存在 `backend/attainment.db`。

### 2. 本地直连已有 MySQL 8.0
先在 MySQL 中建空库（系统首次启动会自动创建全部 4 张表与默认账号）：
```sql
CREATE DATABASE obe_attainment CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
然后设置 `DATABASE_URL` 环境变量并启动：
```powershell
$env:DATABASE_URL = "mysql+pymysql://root:你的密码@127.0.0.1:3306/obe_attainment"
cd backend
.\venv\Scripts\python.exe -m uvicorn api:app --reload --port 8000
```
