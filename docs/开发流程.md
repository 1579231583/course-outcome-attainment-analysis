## 一、需求分析（✅ 已完成）

### 1.1 核心业务场景

高校教师每学期需要完成"课程目标达成度"的统计与上报（工程教育认证/OBE 核心材料）。现状是靠 Excel 手工计算，繁琐且容易出错。本系统将全流程数字化。

### 1.2 达成度算法（已用真实数据验证）

五步计算流程，详见 [达成度计算流程.md](./达成度计算流程.md)。

关键公式：
$$产出权重_{ij} = 考核环节权重_j \times \frac{原始对应比例_{ij}}{\sum_i 原始对应比例_{ij}}$$
$$课程目标达成度_i = \frac{\text{全班实得均分}_i}{\text{理论满分}_i}$$

> ✅ 已用 44 人真实班级数据完整验证，各项数字与学校实际报表完全吻合（目标1达成度55%、目标2达成度74%）。

### 1.3 教师操作流程

```
①网页配置课程规则（只做一次，可复用）
        ↓
②配置或上传试卷结构（大题 → 小题）
        ↓
③系统生成定制成绩录入模板（.xlsx）
        ↓
④教师填好平时及期末小题分数后上传 Excel
        ↓
⑤列映射确认抽屉（字段核对）→ 超分标红 → 就地双击纠错
        ↓
⑥一键触发计算 → 秒级出结果
        ↓
⑦网页查看：达成度卡片 + 评价终表 + 柱状图
        ↓
⑧一键导出官方 Excel 报表（评价汇总表 + 全班明细表）
```

### 1.4 数据录入方式分工

| 录入方式 | 适用内容 | 理由 |
|---------|---------|------|
| **网页端交互表单** | 课程基本信息、考核环节及占比（成绩评定方法）、课程目标与环节对应关系矩阵 | 参数少，实时联动预览产出权重，配置直观 |
| **Excel 批量上传** | 平时成绩明细（学号、姓名、各环节得分）、期末各小题得分 | 数据量大，教师最习惯 Excel 操作 |
| **已确定** | 期末试卷结构采用“大题分组 + 小题明细”，支持网页批量配置或上传一行一个小题的结构模板；每道小题只对应一个课程目标 | 实现结构模板、成绩模板和校验 |

### 1.5 架构决策摘要

| 决策点 | 结论 | 理由 |
|-------|------|------|
| 数据库选型 | **MySQL** | 生产级关系型数据库，支撑用户系统，项目架构完整 |
| 数据库存储范围 | 仅存用户账号 + 报告摘要 | 海量小题成绩不入库，避免数据库臃肿，Pandas 内存算完即可 |
| 计算引擎 | Pandas + numpy 内存计算 | 44人班级数据毫秒级完成，零数据库读写压力 |
| 班级单元 | 单班级核算 | 不做跨班合并，逻辑清晰 |
| 学生名单 | 教师自行复制粘贴 | 不维护学籍库，系统保持轻量 |
| AI 扩展 | 预留接口，不影响当前开发 | 后续版本再接入 |

### 1.6 计算结果呈现设计

**网页端三层展示**（由上至下）：
1. **指标卡片**：大字显示各目标达成度%，绿色=达标，黄色=未达标
2. **评价终表预览**：满分行 + 实得均分行 + 达成度，所见即所得
3. **柱状对比图**：带合格基准红虚线，可右键复制图片

**导出按钮（两个）**：
- 《评价汇总表.xlsx》→ 供教务存档 / 工程认证核查
- 《全班得分明细表.xlsx》→ 逐人逐题数据，供备查
